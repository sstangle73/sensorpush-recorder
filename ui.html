Comfort Presets

Sets the temperature/humidity range counted as "in comfort" on the Stats tab. Sensors inherit their group's defaults; per-sensor entries override the group. Blank = no comfort metric.

Sensor Pairs (Calibration Drift)

Pair two sensors that measure the same environment. The Stats tab's Calibration panel will compare them and flag pairs whose 30-day delta is trending — usually a sign one sensor's calibration is drifting.

↔
Drift thresholds

A pair is flagged "drifting" when its 30-day slope exceeds these per-day thresholds.

HVAC

Flag the sensor(s) closest to your thermostat — they drive duty-cycle inference on the Stats tab. If nothing is flagged, the most-stable indoor sensor (lowest 24 h variance) is used automatically.

Heating zone groups sensors driven by the same heating system (e.g. all rooms on a shared furnace). Cycles are averaged across the zone for a higher-confidence signal. Cooling zone is independent — typically one zone per window-AC unit; leave blank if cooling is per-room.

Backfill Historical Data

Re-fetch all sensor readings from SensorPush from a start date to now. Safe to run anytime — existing data is never overwritten.

Notifications

Outbound alerts to a webhook URL or ntfy.sh topic. Each enabled condition fires once on the transition into "active" and once on the transition back to "recovered". Stuck conditions don't re-buzz.

Sinks

ntfy.sh has no accounts on the free tier — anyone who knows your topic name can read or post to it. Use Generate for a long random topic, then subscribe in the ntfy app or via curl -s https://ntfy.sh/<topic>/json.

Backups

Daily SQLite snapshots are written automatically at 03:30 to /data/backups/ (7-day retention). Restore swaps the live DB to the chosen snapshot; a pre-restore safety copy is preserved before the swap.

Security

A token gates everything but the health check, metrics and this page. A browser signs in once with the token and stays signed in for 90 days with a cookie that page scripts can't read. Programmatic callers (the rosestorie dashboard, scripts, etc.) send Authorization: Bearer <token>. Rotating the token signs every browser out.
