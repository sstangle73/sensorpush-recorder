Comfort Presets

Sets the temperature/humidity range counted as "in comfort" on the Stats tab. Sensors inherit their group's defaults; per-sensor entries override the group. Blank = no comfort metric.

Security

A bearer token gates non-public routes. Browsers loading the Explorer UI from this hostname bypass it via Sec-Fetch-Site: same-origin; cross-origin programmatic callers (the rosestorie dashboard, etc.) must include Authorization: Bearer <token>.
